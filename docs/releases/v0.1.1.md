# AgentContext v0.1.1

A fix release for Claude Code users, plus an agent skill and a one-command
Claude Code plugin.

## Fixed: Claude Code now sees the optimized content

Claude Code shows the model only a tool result's `structuredContent`. In
v0.1.0 that held metadata only, so in Claude Code the model never saw the
optimized or recovered text. All tools now put the content first in
`structuredContent`, with compact omitted-segment summaries and a recovery hint.

Measured in Claude Code on a 1,000-line test log ("what failed and why?"):

| | Turns | Cost |
|---|---|---|
| v0.1.0 | 14 | $0.33 |
| v0.1.1 | 5 | $0.09 |

With v0.1.1 a single `read_file` call returned the log at 2.7k instead of 22k
tokens (87.6% fewer), and the answer was complete.

## New: agent skill and Claude Code plugin

```text
/plugin install agentcontext --marketplace Johannes7549/AgentContext
```

The plugin installs the MCP server together with the `agentcontext` skill, which
tells the agent to read long files and logs through AgentContext and to recover
omitted parts instead of re-reading them. The skill uses the open Agent Skills
format and can be used by other skill-compatible agents.

## Upgrading

`npx -y @agentcontext/mcp-server` picks up 0.1.1 automatically. If you pinned
`0.1.0`, update the version. Plugin users get it on the next plugin update.

All `@agentcontext/*` packages are at 0.1.1 (Apache-2.0).
