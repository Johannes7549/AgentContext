## Before tagging (owner actions)

1. Create the npm organization `agentcontext` and add the `NPM_TOKEN`
   repository secret ([releasing guide](../releasing.md)).
2. Optional but recommended: run the server from this checkout in Claude Code
   (`claude mcp add agentcontext -- node <repo>/apps/mcp-server/dist/cli.js`)
   and call `optimize_context` once.
3. Tag `v0.1.0` and push the tag; the release workflow publishes and creates
   the GitHub release.
