# AgentContext v0.1.0

AgentContext is a local-first MCP server that shrinks oversized tool output —
test logs, JSON responses, long documents, source files and diffs — while
keeping the original on your machine so any omitted part can be recovered
exactly. Deterministic, no LLM calls, no API key, no telemetry.

## Install

Requires Node.js ≥ 22.13.

```sh
claude mcp add agentcontext -- npx -y @agentcontext/mcp-server
# Windows
claude mcp add agentcontext -- cmd /c npx -y @agentcontext/mcp-server
```

## Highlights

- Five MCP tools: `optimize_context`, `retrieve_context`, `read_file`,
  `get_optimization_stats`, and opt-in `execute_command`.
- Five deterministic strategies: logs, JSON, duplicates, Markdown sections,
  code line ranges and diffs. Without a selection only exact repeats are
  collapsed; with one you choose exactly what to keep.
- Every omission is recorded with its original location and is recoverable
  byte-for-byte by segment id, line range, JSONPath, keyword, or in full.
- Recovery is claimed only after the original is stored and its hash verified.
- Budgets (`maxTokens`, `targetReduction`) never truncate; they warn instead.
- Sandboxed file reading; command execution disabled by default and never
  through a shell.

## Benchmarks

Seven reproducible scenarios, counting recovered content and using one
tokenizer (estimates):

| Median reduction | Extraction accuracy | Recovery integrity | Unrecoverable omissions | Task success |
|---|---|---|---|---|
| 86.6% | 100% | 100% | 0 | 7/7 |

Full report attached (`latest.md`). Datasets are synthetic and task quality is
measured by a deterministic oracle, not a live model.

## Known limitations

Estimated token counts; no interception of other MCP servers (planned gateway
in v0.2); MCP content-block arrays returned unchanged; restricted JSONPath;
no AST parsing; Windows `.cmd`/`.bat` shims cannot be run by
`execute_command`; local storage is not encrypted. See
[docs/limitations.md](https://github.com/Johannes7549/AgentContext/blob/main/docs/limitations.md).
