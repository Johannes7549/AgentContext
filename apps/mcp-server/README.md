# @agentcontext/mcp-server

AgentContext MCP server: reversible context optimization for AI agents (stdio).

```sh
# Claude Code
claude mcp add agentcontext -- npx -y @agentcontext/mcp-server
```

Requires Node.js >= 22.13. Tools: `optimize_context`, `retrieve_context`, `read_file`, `execute_command` (opt-in), `get_optimization_stats`.

Documentation: https://github.com/Johannes7549/AgentContext#readme
