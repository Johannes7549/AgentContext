# @agentcontext/storage

Local SQLite + blob storage for AgentContext originals.

Part of [AgentContext](https://github.com/Johannes7549/AgentContext); most users want [`@agentcontext/mcp-server`](https://www.npmjs.com/package/@agentcontext/mcp-server) or, for embedding, [`@agentcontext/core`](https://www.npmjs.com/package/@agentcontext/core).

Requires Node.js >= 22.13. License: Apache-2.0
